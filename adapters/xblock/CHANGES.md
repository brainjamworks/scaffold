# Scaffold XBlock changelog

This file records user-visible changes to the Open edX XBlock.

## Unreleased

## 0.1.1 - 2026-07-27

- Added runtime support for Python 3.11 or later and XBlock 5.2 through 6.x,
  including the Open edX Ulmo baseline.
- Kept the Python 3.12 requirement for maintainer build and packaging tooling
  separate from the installed XBlock runtime requirement.

## 0.1.0 - 2026-07-27

- Added verified wheel and source-distribution packaging for the first
  coordinated Scaffold release.
